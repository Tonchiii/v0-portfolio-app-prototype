Place your certificate image(s) in this folder so they can be displayed on the site.

Expected filename(s):
- html-css-cert.png  (used by the HTML & CSS certification entry)

How to add the file (PowerShell):
# from the folder that contains your downloaded certificate image
Copy-Item -Path .\path\to\your\certificate.png -Destination .\\public\\certificates\\html-css-cert.png

Or drag the image into this folder in your editor/IDE.

Once the image is present, the site will render it on the Education & Expertise card. If you want me to add the image file for you, upload the original PNG here in the chat and I will write it into this folder for you.
